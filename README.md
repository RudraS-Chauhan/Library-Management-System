# 📚 Enterprise Library Engine (CLI)
**Robust Logistics and Transaction Management**

A high-performance Command Line Interface (CLI) application engineered in pure Java. This system was built to handle complex logistical tracking, replacing manual library management with automated, algorithmic data handling.

---

## 🚀 Core System Architecture
This engine is built strictly on Object-Oriented Programming (OOP) principles, ensuring modularity, clean data encapsulation, and scalable transaction processing.

* **Dynamic Overdue Algorithms:** Custom logic engineered to automatically calculate precise late fees based on time-deltas.
* **Transaction Management:** Real-time tracking of checkout/return lifecycles with error handling for inventory conflicts.
* **Automated Receipt Generation:** Synthesizes transaction data into clean, professional receipt outputs for the end-user.
* **Persistent Record Keeping:** Maintains strict oversight of all active and historical inventory states.

## ⚙️ Tech Stack & Concepts
* **Language:** Java (JDK)
* **Design Patterns:** Strict OOP (Inheritance, Polymorphism, Encapsulation)
* **Interface:** Command Line / Terminal
